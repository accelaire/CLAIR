La documentation présente les versions de CLAIR (v0.1.0 à v0.5.0) et la règle de publication d'une version. Chaque pull request notable y ajoute un fragment dans `.changelog/`. L'API annonce sa version (`GET /health`, champ `version` ; OpenAPI `info.version`). `AGENTS.md` résume les règles du dépôt pour les agents de code.
