---

Une chaîne d'ingestion transforme chaque nuit des sources hétérogènes (JSON, XML, CSV, XLSX, dumps SQL, pages HTML, PDF) en un modèle unique stocké dans PostgreSQL, puis relie les entités entre elles, calcule les statistiques et rédige les résumés IA.
