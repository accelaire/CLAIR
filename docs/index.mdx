**CLAIR** (*Citoyen Libre, Analyse, Information, République*) est une plateforme ouverte et indépendante dédiée à la transparence sur le Parlement français : parlementaires, scrutins publics, dossiers législatifs, débats, commissions et lobbying. L'ensemble du code est publié sous licence **AGPL-3.0**.

---

## 🏛️ Vue d'Ensemble de l'Écosystème

L'écosystème CLAIR s'articule autour d'une base de données relationnelle centralisée alimentée par des pipelines d'ingestion quotidiens et mise à disposition via une API en lecture seule et une application web accessible sur [clair.vote](https://clair.vote).

## 🔒 Principes d'Accès et Transparence

- **Lecture Seule et Zéro Compte** : La plateforme ne comporte aucun système de compte utilisateur, ni cookie traceur. L'API est publique et consultable librement.
- **Licence Libre AGPL-3.0** : Le code source de l'ensemble des modules (Web, API, Ingestion, Docs) est public.
- **Traçabilité Intégrale** : Chaque donnée affichée est directement rattachable à son document légal source ou son identifiant officiel (UID AN/Sénat, déclaration HATVP).
