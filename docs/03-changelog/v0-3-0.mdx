## En bref

La v0.3.0 introduit l'**enrichissement par IA** (Mistral) : des résumés de scrutins, de dossiers et de sujets, toujours signalés comme tels. Elle crée les **sujets**, qui regroupent les dossiers d'une même question, une page de **classements**, des secteurs normalisés pour le **lobbying**, et simplifie l'architecture en retirant Meilisearch, BullMQ et le simulateur.

| Pour qui | Ce qui change |
|---|---|
| Citoyens | résumés IA avec avertissement, pages [sujets](https://clair.vote/sujets) et [classements](https://clair.vote/classements), fiches enrichies (mandats, déclarations HATVP), mode sombre, pages pédagogiques |
| Réutilisateurs | module `sujets`, secteurs du lobbying, Swagger public et page [/api](https://clair.vote/api) |
| Contributeurs | commande `enrich-ia`, contrôles qualité de l'IA, architecture simplifiée |

Le hash du contenu évite de redemander un résumé quand rien n'a changé ; un contrôle dédié détecte les résumés qui inversent le sens d'un vote.

## Les sujets et les secteurs dans l'API

```bash
# Les sujets suivis (regroupements de dossiers)
curl "https://api.clair.vote/api/v1/sujets?limit=5"

# Les secteurs du lobbying, avec le nombre de lobbyistes et d'actions
curl "https://api.clair.vote/api/v1/lobbying/secteurs"
```

Les sujets sont produits par un générateur déterministe (Union-Find) : les mêmes dossiers donnent toujours les mêmes sujets.
