## 🏢 Organisation du Monorepo

Le projet est structuré sous forme de monorepo géré avec `pnpm workspaces` et `Turborepo` :

```text
CLAIR/
├── apps/
│   ├── web/              # Application Frontend Next.js 14 (App Router) — clair.vote
│   └── api/              # API REST Fastify 4 + Prisma — api.clair.vote
│       └── prisma/       # schema.prisma, migrations et seed
├── services/
│   └── ingestion/        # Worker & CLI d'ingestion : sources publiques → PostgreSQL
├── docs/                 # Documentation Zudoku — docs.clair.vote
├── packages/
│   ├── config/           # Configurations partagées
│   └── shared/           # Types et utilitaires partagés
├── scripts/              # Scripts ponctuels (audits, géographie, logos)
├── Dockerfile            # Image de production de l'API
└── docker-compose.yml    # Environnement PostgreSQL + Redis de développement
```
