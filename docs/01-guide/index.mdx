## 🏢 Organisation du monorepo

Monorepo pnpm géré par [Turborepo](https://turbo.build/repo). Quatre workspaces portent le code ; les deux paquets de `packages/` sont aujourd'hui des coquilles vides.

```text
CLAIR/
├── apps/
│   ├── web/              # Frontend Next.js 14 (App Router), clair.vote, hébergé sur Vercel
│   └── api/              # API Fastify + Prisma, lecture seule, api.clair.vote, hébergée sur Railway
│       └── prisma/       # schema.prisma (source de vérité du modèle), migrations, triggers, seed
├── services/
│   └── ingestion/        # CLI d'ingestion : sources publiques → PostgreSQL,
│                         # rattachements, statistiques, enrichissement IA
├── docs/                 # Cette documentation (Zudoku), docs.clair.vote
├── packages/
│   ├── config/           # Vide (module.exports = {})
│   └── shared/           # Vide (export {})
├── scripts/              # Scripts ponctuels (audits, logos de groupes, géographie)
├── Dockerfile            # Image de l'API
├── docker-compose.yml    # PostgreSQL + Redis pour le développement local
└── .github/workflows/    # CI (lint, tests, build)
```

La plateforme n'a **ni comptes utilisateurs, ni authentification** : l'API est publique et en lecture seule. La seule écriture publique est l'envoi d'un retour anonyme (`POST /api/v1/feedback`).

## 🗺️ Pages du site

| Route | Contenu |
| :--- | :--- |
| `/` | Accueil |
| `/deputes`, `/deputes/[slug]`, `/deputes/comparer` | Députés : liste, fiche, comparateur |
| `/senateurs`, `/senateurs/[slug]`, `/senateurs/comparer` | Sénateurs : liste, fiche, comparateur |
| `/groupes`, `/groupes/[chambre]/[slug]` | Groupes politiques de l'Assemblée et du Sénat |
| `/scrutins`, `/scrutins/[numero]` | Scrutins publics des deux chambres |
| `/votes`, `/votes/[year]`, `/votes/[year]/[month]` | Archives des scrutins, par année et par mois |
| `/dossiers`, `/dossiers/[uid]` | Dossiers législatifs |
| `/sujets`, `/sujets/[slug]` | Sujets : regroupement des dossiers AN et Sénat portant sur le même texte |
| `/commissions`, `/commissions/[slug]` | Commissions et organes |
| `/agenda`, `/reunions/[uid]` | Agenda parlementaire, réunions et séances |
| `/lobbying`, `/lobbying/[id]`, `/lobbying/actions` | Représentants d'intérêts et actions déclarées (HATVP) |
| `/senatoriales-2026`, `/senatoriales-2026/[departement]`, `/senatoriales-2026/graphiques/[slug]` | Élections sénatoriales 2026 : bilan des sortants, candidats, résultats |
| `/classements` | Classements des parlementaires |
| `/explorateur` | Explorateur de données |
| `/recherche` | Recherche globale |
| `/api` | Présentation de l'API publique |
| `/comprendre/*` | Pages pédagogiques (Parlement, parlementaire, scrutin, dossier législatif, commissions, groupes, lobbying) |
| `/guide/*` | Guides d'usage |
| `/methodologie` | Méthodologie des statistiques et de l'IA |
| `/soutenir` | Dons (formulaire HelloAsso intégré) |
| `/a-propos`, `/contact`, `/cgu`, `/confidentialite`, `/mentions-legales` | Pages institutionnelles |
