## 🌐 Vue d'Ensemble de l'Infrastructure

| Composant | Hébergeur | Déclenchement et Planification | URL Publique |
| :--- | :--- | :--- | :--- |
| **Frontend Web (`apps/web`)** | Vercel (Région `cdg1` Paris) | Déploiement continu sur `master` | [`clair.vote`](https://clair.vote) |
| **Documentation (`docs/`)** | Vercel (Région `cdg1` Paris) | Déploiement continu sur `master` | [`docs.clair.vote`](https://docs.clair.vote) |
| **API REST (`apps/api`)** | Railway (Conteneur Docker) | Déploiement continu sur `master` | [`api.clair.vote`](https://api.clair.vote) |
| **Batch Nocturne** | Railway Worker | Cron `0 3 * * *` (UTC) | *(Service interne)* |
| **Batch Intraday** | Railway Worker | Cron `0 6-21/2 * * *` (UTC) | *(Service interne)* |
| **Base PostgreSQL 17** | Railway Managé avec SSL | Permanent avec sauvegardes | *(Réseau privé Railway)* |
| **Cluster Redis 8** | Railway Managé | Permanent | *(Réseau privé Railway)* |

## ⚙️ Déploiement du Portail Zudoku (`docs.clair.vote`)

Le portail de documentation est configuré dans `docs/vercel.json` :
- **Framework** : `vite`
- **Build Command** : `pnpm build`
- **Output Directory** : `dist`
- **Domaine rattaché** : `docs.clair.vote`
