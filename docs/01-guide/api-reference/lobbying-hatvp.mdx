Les données viennent du répertoire des représentants d'intérêts de la HATVP (voir [Sources de données](/donnees/sources-de-donnees)). Les secteurs sont normalisés dans la table `secteurs` et rattachés aux lobbyistes comme aux actions.

## 🏢 Routes

| Méthode | Route | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/lobbying` | Liste paginée des représentants d'intérêts, filtrable par `secteurs` (slugs séparés par des virgules, tous requis) et `search` (nom) |
| `GET` | `/api/v1/lobbying/secteurs` | Secteurs normalisés, avec le nombre de lobbyistes et d'actions de chacun |
| `GET` | `/api/v1/lobbying/stats` | Statistiques d'ensemble : totaux, répartition par type, secteurs principaux |
| `GET` | `/api/v1/lobbying/actions` | Actions déclarées, paginées, filtrables notamment par texte visé et par secteurs |
| `GET` | `/api/v1/lobbying/actions/recent` | Dernières actions déclarées |
| `GET` | `/api/v1/lobbying/:id` | Fiche d'un représentant d'intérêts |
| `GET` | `/api/v1/lobbying/:id/actions` | Actions déclarées par un représentant d'intérêts |

Paramètres et schémas de réponse : [explorateur de l'API](/api). Les réponses de ce module sont mises en cache 12 h.
