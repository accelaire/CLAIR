Les trois préfixes servent les mêmes routes sur la même table : `/parlementaires` couvre les deux chambres, `/deputes` et `/senateurs` sont restreints à l'une d'elles. Une personne passée par les deux chambres n'a qu'une fiche (voir [Modèle Prisma](/donnees/modele-prisma)).

---

## 👥 Routes principales

| Méthode | Route | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/parlementaires` | Liste paginée des parlementaires (Assemblée et Sénat) |
| `GET` | `/api/v1/deputes` | Même liste, restreinte aux députés |
| `GET` | `/api/v1/senateurs` | Même liste, restreinte aux sénateurs |
| `GET` | `/api/v1/parlementaires/:slug` | Fiche d'un parlementaire : identité, mandats, statistiques, fiche IA |
| `GET` | `/api/v1/parlementaires/:slug/votes` | Votes du parlementaire, filtrables |
| `GET` | `/api/v1/parlementaires/:slug/amendements` | Amendements déposés et cosignés |
| `GET` | `/api/v1/parlementaires/:slug/interventions` | Prises de parole en séance et en commission |
| `GET` | `/api/v1/parlementaires/compare?slugs=a,b` | Comparaison de 2 à 4 parlementaires par leurs statistiques |

Toutes les routes, avec leurs schémas de réponse : [explorateur de l'API](/api).

## 🏛️ Filtres de la liste

| Paramètre | Effet |
| :--- | :--- |
| `page`, `limit` | Pagination (`limit` jusqu'à 200, 20 par défaut) |
| `chambre` | `assemblee` ou `senat` |
| `groupe` | Slug du groupe politique |
| `departement` | Numéro de département (`78`, `2A`, `974`…) |
| `search` | Recherche sur le nom et le prénom |
| `actif` | `true` (en exercice, par défaut) ou `false` |
| `legislature` | Députés ayant siégé sous cette législature (15, 16 ou 17) ; renvoie le groupe et la circonscription de cette période |
| `session` | Sénateurs ayant siégé pendant cette session (`2024-2025`) ; renvoie le groupe et la circonscription de la période |
| `sort` | `nom` (par défaut), `prenom`, `presence`, `loyaute`, `activite`, `amendements`, `interventions` |
| `order` | `asc` (par défaut) ou `desc` |
| `periode` | Statistiques servant au tri : `mandat` (mandat en cours, par défaut) ou `carriere` (tous mandats cumulés, ce qui avantage mécaniquement les réélus) |

## 🗳️ Votes d'un parlementaire

`GET /api/v1/parlementaires/:slug/votes` accepte `page`, `limit` (jusqu'à 100), `position` (`pour`, `contre`, `abstention`, `absent`), `tag`, `dateFrom`, `dateTo`, `dissidentOnly` (seulement les votes différents de la position majoritaire du groupe) et, pour une personne passée par les deux chambres, `chambre`. Le groupe d'un vote est celui du mandat à la date du scrutin, pas le groupe actuel.
