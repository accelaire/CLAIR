## 🗳️ Endpoints Disponibles

| Méthode | Route | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/scrutins` | Liste paginée des scrutins publics avec filtres temporels et thématiques |
| `GET` | `/api/v1/scrutins/importants` | Scrutins majeurs ou solennels mis en avant |
| `GET` | `/api/v1/scrutins/tags` | Liste des mots-clés et tags de classification |
| `GET` | `/api/v1/scrutins/:numero` | Détail d'un scrutin (objet, synthèse IA, sort, décompte) |
| `GET` | `/api/v1/scrutins/:numero/votes` | Liste complète de tous les votes nominatifs des élus |
| `GET` | `/api/v1/scrutins/:numero/interventions` | Débats et prises de parole ayant précédé le vote |

---

## 🏷️ Positions de Vote Prises en Charge

Chaque vote nominatif d'un élu est classé selon l'une des positions officielles :

- **POUR** : `pour`
- **CONTRE** : `contre`
- **ABSTENTION** : `abstention`
- **NON_VOTANT / ABSENT** : `non_votant` ou `absent`
