Le site actuel (`apps/web`) reste en ligne et **n'est pas modifié**. Le nouveau front se construit à côté, dans `apps/site`, écran par écran, sur une architecture reprise de [democracy-watch](https://github.com/dataforgoodfr/democracy-watch) : des routes minces, des écrans testables sans serveur, des composants documentés et un design system unique. Il est déployé sur `beta.clair.vote` pendant la migration, puis remplace le site actuel sur `clair.vote`.

## Deux catalogues, deux rôles

| | Ce catalogue (docs.clair.vote) | Storybook ([storybook.clair.vote](https://storybook.clair.vote), `apps/storybook`) |
|---|---|---|
| Pour qui | toute personne qui utilise un composant | qui développe un composant |
| Contenu | comment l'utiliser : import, usage de base, variantes, avec le rendu réel | toutes les variantes et tous les états, en clair, en sombre et sur chaque taille d'écran |
| Garanties | un test vérifie le gabarit de chaque page | chaque story est un test : rendu dans Chromium et accessibilité vérifiée par axe |

Un composant exporté par `@clair/ui` a toujours les deux : chaque page du catalogue renvoie à ses variantes dans l'atelier. Mise en ligne de l'atelier et du site bêta : [Déploiement](/front/architecture/deploiement).
