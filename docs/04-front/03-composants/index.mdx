## Ajouter un composant

1. Créer le dossier `packages/ui/src/<catégorie>/<nom>/` : `Nom.tsx`, `Nom.module.css` (uniquement des `var(--clair-…)`), `Nom.stories.tsx`, `Nom.test.tsx`, `index.ts`.
2. L'exporter dans `packages/ui/src/index.ts`.
3. Lui créer une page dans le dossier de sa famille (`docs/04-front/03-composants/<famille>/<nom>.mdx`), sur le modèle de [Badge](/front/composants/fondations/badge) : Import, Utilisation de base, puis une section « Avec … » par variante, chacune avec un aperçu `<Preview>` et le code.
4. `pnpm docs:nav`, puis `pnpm docs:validate`.

Le skill `clair-composant` décrit chaque étape ; un test vérifie que chaque page respecte ce gabarit.
