import { Button } from "@clair/ui";
import { ArrowRight, Share2 } from "lucide-react";

Bouton d'action, à réserver aux actions (une seule action primaire par zone) : avec `href`, il rend un lien au même aspect, interne par le routeur de l'application ou externe dans un nouvel onglet annoncé. Une icône seule exige un `aria-label`, imposé par le type. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-button--docs)

## Import

```tsx
import { Button } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <Button>Télécharger les données</Button>
</Preview>

```tsx
<Button onClick={telecharger}>Télécharger les données</Button>
```
