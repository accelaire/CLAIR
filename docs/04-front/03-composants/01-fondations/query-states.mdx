import { EmptyState, ErrorState, LoadingState } from "@clair/ui";

Trois composants pour les états d'un écran qui charge des données (règle des 6 états UI) : `LoadingState` annonce le chargement (`role="status"`), `ErrorState` annonce une erreur récupérable (`role="alert"`) avec un bouton « Réessayer », `EmptyState` explique un résultat vide et propose une action. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-querystates--docs)

## Import

```tsx
import { EmptyState, ErrorState, LoadingState } from "@clair/ui";
```
