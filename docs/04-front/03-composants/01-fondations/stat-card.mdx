import { StatCard } from "@clair/ui";
import { ShieldCheck } from "lucide-react";

Chiffre clé et son libellé, dans une liste de définitions (`dl`), en chiffres tabulaires. La variation est écrite en toutes lettres (« Hausse de 3,2 points ») et reste de ton neutre : une hausse n'est ni bonne ni mauvaise en soi. Fusionne les deux `StatCard` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-statcard--docs)

## Import

```tsx
import { StatCard } from "@clair/ui";
```
