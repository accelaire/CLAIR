import { Link } from "@clair/ui";

Lien de texte. Un lien interne est rendu par le routeur de l'application : aucun composant ne dépend de Next.js. Un lien externe s'ouvre dans un nouvel onglet, avec une icône et la mention « nouvelle fenêtre » pour les lecteurs d'écran. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-link--docs)

## Import

```tsx
import { Link } from "@clair/ui";
```
