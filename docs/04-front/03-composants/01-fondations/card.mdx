import { Badge, Card } from "@clair/ui";

Surface qui regroupe un contenu, avec titre (niveau choisi par `titleAs`), surtitre et pied facultatifs. Cliquable avec `href` : le titre est l'unique lien et sa zone couvre toute la carte, qui ne doit contenir aucun autre élément interactif. Remplace `.depute-card` et `.stat-card` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-card--docs)

## Import

```tsx
import { Card } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <Card title="Camille Exemple">Députée de la 1re circonscription de l'Exemple-sur-Mer.</Card>
</Preview>

```tsx
<Card title="Camille Exemple">Députée de la 1re circonscription de l'Exemple-sur-Mer.</Card>
```

## Avec un en-tête et un pied

  <Card
    title="Camille Exemple"
    titleAs="h2"

    footer="Mandat en cours depuis 2024"

  </Card>
</Preview>
