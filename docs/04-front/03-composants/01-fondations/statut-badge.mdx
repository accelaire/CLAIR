import { StatutBadge } from "@clair/ui";

Statut législatif : sort d'un scrutin ou d'un amendement, état d'un dossier. Le ton vient du mapping central `STATUTS` et le libellé porte toujours l'information ; `parseStatut` convertit une valeur brute de l'API (« Adopté », `rejete`, « Cavalier (45) »…). [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-statutbadge--docs)

## Import

```tsx
import { parseStatut, StatutBadge } from "@clair/ui";
```
