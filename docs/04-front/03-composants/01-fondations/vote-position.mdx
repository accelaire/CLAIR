import { VotePosition } from "@clair/ui";

Position de vote d'un parlementaire sur un scrutin. Chaque position a une icône et un libellé en plus de sa couleur : l'information ne repose jamais sur la couleur seule. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-voteposition--docs)

## Import

```tsx
import { VotePosition } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <VotePosition position="pour" />
</Preview>

```tsx
<VotePosition position="pour" />
```
