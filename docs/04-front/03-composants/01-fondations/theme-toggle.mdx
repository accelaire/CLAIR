Bouton de bascule entre les thèmes clair et sombre. Son nom accessible annonce le thème vers lequel il bascule. Il est inclus dans `Header`. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-themetoggle--docs)

## Import

```tsx
import { ThemeToggle } from "@clair/ui";
```
