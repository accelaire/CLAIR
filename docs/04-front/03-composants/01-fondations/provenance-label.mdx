import { ProvenanceLabel } from "@clair/ui";

Indique la nature d'une donnée. Règle centrale de CLAIR : toujours distinguer la donnée **officielle** (source institutionnelle), la donnée **calculée** par CLAIR et la donnée **générée par IA**, à vérifier. Le libellé porte l'information, l'icône est décorative, et un lien peut mener à la méthodologie. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-provenancelabel--docs)

## Import

```tsx
import { ProvenanceLabel } from "@clair/ui";
```
