import { ChambreBadge } from "@clair/ui";

Chambre du Parlement, avec la couleur propre à chaque chambre toujours doublée de son nom. En version courte (« AN »), le nom complet est donné en infobulle et lu par les lecteurs d'écran. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-chambrebadge--docs)

## Import

```tsx
import { ChambreBadge } from "@clair/ui";
```
