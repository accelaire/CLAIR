import { Callout } from "@clair/ui";
import { Heart } from "lucide-react";

Encart qui attire l'attention sur une information, une invitation ou un avertissement ; l'icône et le titre portent le sens, jamais la couleur seule. Il propose au plus une action, un lien. Remplace `FicheCompareCallout`, `SiegeRenouvelableCallout`, `SoutenirCallout` et `EncartResultats` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-callout--docs)

## Import

```tsx
import { Callout } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <Callout title="Siège remis en jeu le 27 septembre 2026">
    Ce siège fait partie des sièges renouvelés avec la série 2 du Sénat.
  </Callout>
</Preview>

```tsx
<Callout title="Siège remis en jeu le 27 septembre 2026">
  Ce siège fait partie des sièges renouvelés avec la série 2 du Sénat.
</Callout>
```

  </Callout>
