import { Badge } from "@clair/ui";
import { Check } from "lucide-react";

Étiquette courte de statut ou de catégorie. La couleur n'est jamais seule : le libellé porte l'information. Remplace les classes `.badge-*` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-badge--docs)

## Import

```tsx
import { Badge } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <Badge>Caduc</Badge>
</Preview>

```tsx
<Badge>Caduc</Badge>
```
