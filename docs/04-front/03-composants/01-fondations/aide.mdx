import { Aide } from "@clair/ui";

Bulle d'aide placée à côté d'un terme ou d'un chiffre. Elle s'ouvre au clic, au toucher ou avec Entrée (jamais au seul survol), se ferme avec Échap ou par un clic à l'extérieur et rend le focus au bouton, nommé « Aide : *sujet* » pour les lecteurs d'écran. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-fondations-aide--docs)

## Import

```tsx
import { Aide } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <p>
    {"Taux de participation "}
