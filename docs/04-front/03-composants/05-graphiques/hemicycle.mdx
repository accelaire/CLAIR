import { ChartFrame, Hemicycle } from "@clair/ui";

Hémicycle dessiné en SVG (577 sièges à l'Assemblée nationale, 348 au Sénat). Les groupes sont placés de gauche à droite dans l'ordre fourni par les données ; un groupe sans couleur prend la palette des graphiques. L'image est nommée par son titre et décrite en texte, la légende donne le sigle et le nombre de sièges de chaque groupe ; survoler ou parcourir la légende au clavier met en avant les sièges d'un groupe. Les répartitions ci-dessous sont des exemples. Remplace `HemicycleChart` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-graphiques-hemicycle--docs)

## Import

```tsx
import { Hemicycle } from "@clair/ui";
```
