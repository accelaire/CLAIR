import { BarChart, ChartFrame } from "@clair/ui";

Cadre commun des graphiques de CLAIR. Il porte le titre, le sous-titre, la nature de la donnée (officielle, calculée par CLAIR ou générée par IA, via `ProvenanceLabel`), la source, et une alternative textuelle obligatoire : le bouton « Afficher les données » révèle le tableau des mêmes valeurs. Remplace `CadreGraphique` et `ChartTooltip` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-graphiques-chartframe--docs)

## Import

```tsx
import { ChartFrame } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <ChartFrame
    title="Votes d'un groupe par mois"
    subtitle="Données d'exemple"
    provenance="calculee"
    table={{
      caption: "Votes par mois (exemple)",
      columns: [
        { key: "mois", label: "Mois" },
        { key: "pour", label: "Pour" },
        { key: "contre", label: "Contre" },
      ],
      rows: [
        { mois: "Janvier", pour: 42, contre: 18 },
        { mois: "Février", pour: 35, contre: 22 },
      ],
    }}
  >
    <BarChart
      categoryKey="mois"
      data={[
        { mois: "Janvier", pour: 42, contre: 18 },
        { mois: "Février", pour: 35, contre: 22 },
      ]}
      series={[
        { key: "pour", label: "Pour", color: "var(--clair-graphique-vote-pour)" },
        { key: "contre", label: "Contre", color: "var(--clair-graphique-vote-contre)" },
      ]}
    />
  </ChartFrame>
</Preview>
