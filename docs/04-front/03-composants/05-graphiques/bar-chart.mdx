import { BarChart, ChartFrame } from "@clair/ui";

Graphique en barres construit sur `BarChart` de `@mantine/charts`. Le dessin est masqué aux lecteurs d'écran : il se place toujours dans un `ChartFrame`, dont le tableau « Afficher les données » est l'alternative textuelle ; la légende des séries reste en texte. Les couleurs viennent des tokens (`--clair-graphique-vote-*`, `--clair-groupe-*`) ou, à défaut, de la palette des graphiques. L'application doit charger `@mantine/charts/styles.css`. Remplace `BarresComptage` et les graphiques Recharts du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-graphiques-barchart--docs)

## Import

```tsx
import { BarChart } from "@clair/ui";
```
