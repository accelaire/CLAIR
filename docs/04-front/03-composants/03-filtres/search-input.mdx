import { SearchInput } from "@clair/ui";

Champ de recherche **contrôlé** : l'écran fournit `value` et `onChange` et synchronise la valeur avec l'URL. Le champ a toujours un nom accessible (`label` visible, ou à défaut `aria-label`) ; l'icône est décorative. Entrée appelle `onSubmit`, Échap ou le bouton « Effacer la recherche » vident le champ et rendent le focus. Avec `debounceMs`, la saisie reste fluide et `onChange` n'est appelé qu'une fois la frappe arrêtée. Remplace `.search-input` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-filtres-searchinput--docs)

## Import

```tsx
import { SearchInput } from "@clair/ui";
```
