import { MultiSelectFilter } from "@clair/ui";

Filtre à choix multiple, **contrôlé** (`value` est la liste des valeurs choisies, à écrire dans l'URL en paramètre répété). La recherche ignore la casse et les accents ; chaque option peut afficher un nombre. Le nombre d'éléments choisis figure dans le libellé et est annoncé aux lecteurs d'écran ; le bouton « Tout désélectionner » est accessible au clavier. Remplace `components/MultiSelectFilter.tsx` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-filtres-multiselectfilter--docs)

## Import

```tsx
import { MultiSelectFilter } from "@clair/ui";
```
