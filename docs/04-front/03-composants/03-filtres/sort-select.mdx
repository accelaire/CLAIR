import { SortSelect } from "@clair/ui";

Choix du tri d'une liste, **contrôlé**. Liste déroulante native : la plus accessible et la plus confortable sur mobile. Le libellé (« Trier par » par défaut) est toujours présent, au besoin masqué visuellement. Remplace `classements/SortSelect.tsx` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-filtres-sortselect--docs)

## Import

```tsx
import { SortSelect } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <SortSelect
    value="presence"
    onChange={() => {}}
    options={[
      { value: "presence", label: "Présence" },
      { value: "loyaute", label: "Loyauté" },
      { value: "nom", label: "Alphabétique" },
    ]}
  />
</Preview>

```tsx
<SortSelect
  value={tri}
  onChange={setTri}
  options={[
    { value: "presence", label: "Présence" },
    { value: "loyaute", label: "Loyauté" },
    { value: "nom", label: "Alphabétique" },
  ]}
/>
```
