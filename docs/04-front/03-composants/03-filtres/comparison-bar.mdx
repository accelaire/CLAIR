import { ComparisonBar } from "@clair/ui";

Barre de comparaison, **contrôlée** : l'écran tient la sélection et fournit l'adresse de la comparaison. Chaque élu est retirable (« Retirer … de la comparaison ») ; le nombre d'élus est annoncé. Sous deux élus, « Comparer » est désactivé et une aide l'explique ; au maximum (`max`, 4 par défaut), un message le signale. La barre est fixée en bas de l'écran (`fixed={false}` pour l'afficher dans le flux, comme ici) et n'apparaît pas sans sélection. Remplace `comparison/ComparisonSelectionBar.tsx` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-filtres-comparisonbar--docs)

## Import

```tsx
import { ComparisonBar } from "@clair/ui";
```
