import { ParlementaireCard } from "@clair/ui";

Carte d'un député ou d'un sénateur (paramètre `chambre`) : photo, nom (unique lien, vers la fiche, dont la zone couvre la carte), groupe, circonscription ou département, et statut (ancien élu). En mode comparateur, une case « Comparer » distincte du lien sélectionne la personne. Remplace `.depute-card`, les cartes des listes des députés et des sénateurs et `SortantCard` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-parlementairecard--docs)

## Import

```tsx
import { ParlementaireCard } from "@clair/ui";
```
