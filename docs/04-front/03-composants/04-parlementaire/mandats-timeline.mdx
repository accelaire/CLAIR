import { MandatsTimeline } from "@clair/ui";

Frise des mandats d'un parlementaire, du plus récent au plus ancien, construite sur `Timeline` de Mantine. Chaque mandat donne sa chambre, sa période, ses dates, le groupe de l'époque (couleur toujours doublée du nom et du sigle), la circonscription et les fonctions exercées : les fonctions en cours sont visibles, les anciennes se déplient. Fusionne `MandatsBlock` et `FonctionsMandat` du site actuel. Exemples : personne fictive. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-mandatstimeline--docs)

## Import

```tsx
import { MandatsTimeline } from "@clair/ui";
```
