import { LegislativeTimeline } from "@clair/ui";

Frise du parcours d'un dossier législatif, construite sur `Timeline` de Mantine. Chaque étape donne sa chambre, sa date et son issue officielle ; l'étape en cours est annoncée par une phrase de résumé et par une mention lue par les lecteurs d'écran, pas seulement par le style. Les étapes suivent la forme renvoyée par l'API. Remplace `LegislativeTimeline` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-legislativetimeline--docs)

## Import

```tsx
import { LegislativeTimeline } from "@clair/ui";
```
