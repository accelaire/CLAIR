import { GroupeBadge } from "@clair/ui";

Groupe politique d'un parlementaire : une pastille de la couleur du groupe et son sigle, toujours affiché (la couleur n'est jamais seule). Le nom complet est donné en infobulle et aux lecteurs d'écran. La couleur vient de l'API (`groupe.couleur`) ; absente, elle se replie sur le token `--clair-groupe-<sigle>`, puis sur le gris des non-inscrits. Remplace `.groupe-badge` et `getGroupColor` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-groupebadge--docs)

## Import

```tsx
import { GroupeBadge } from "@clair/ui";
```
