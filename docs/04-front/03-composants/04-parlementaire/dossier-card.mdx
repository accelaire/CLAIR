import { Badge, DossierCard } from "@clair/ui";

Carte d'un dossier législatif : titre (complété de la procédure s'il commence par un complément), état en badge texte, chambre, date du dernier vote ou du dépôt, nombre de scrutins et d'amendements. Avec `href`, le titre est l'unique lien de la carte ; sans `href`, la carte est statique et donne les liens officiels de la loi promulguée. Fusionne `DossierCard` et `LoiPromulgueeCard` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-dossiercard--docs)

## Import

```tsx
import { DossierCard } from "@clair/ui";
```
