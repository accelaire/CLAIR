import { EvenementCard } from "@clair/ui";

Carte d'un événement de l'agenda : réunion de commission, séance publique ou échéance institutionnelle. Les dates et heures sont données en heure de Paris ; une échéance dont la date n'est pas encore fixée n'affiche que son mois. Pendant l'événement, la mention « En direct » est un texte (l'application calcule l'état avec `isHappeningNow`). Fusionne `EvenementCard` et `ReunionCard` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-evenementcard--docs)

## Import

```tsx
import { EvenementCard } from "@clair/ui";
```
