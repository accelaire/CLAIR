import { AmendementCard } from "@clair/ui";

Carte d'un amendement : numéro, sort en badge texte, article et alinéa visés, auteur et groupe, exposé sommaire et dispositif repliables (« Lire la suite », bouton `aria-expanded`), mention « Sous-amendement à… » et liens vers les scrutins et le dossier. Le HTML de la source est réduit à son texte. Fusionne `ExpandableAmendementCard`, son doublon de la fiche sénateur et `AmendementSeance` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-amendementcard--docs)

## Import

```tsx
import { AmendementCard } from "@clair/ui";
```

## Utilisation de base

    groupe={{ sigle: "ECO", nom: "Écologiste et Social" }}

      alinea: "alinéa 2",
      auteurLibelle: "Mme Camille Exemple",
      sort: "Adopté",

        "Cet amendement d'exemple vise à préciser la rédaction de l'article afin de lever une ambiguïté sur le champ d'application du dispositif. Il prévoit que les modalités seront fixées par décret, après consultation des collectivités concernées.",
      dateDepot: "2026-01-12T00:00:00.000Z",
    }}
  />
</Preview>
