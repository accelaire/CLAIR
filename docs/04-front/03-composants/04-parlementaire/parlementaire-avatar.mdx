import { ParlementaireAvatar } from "@clair/ui";

Photo officielle d'un député ou d'un sénateur. Sans photo, ou si elle ne se charge pas, les initiales la remplacent. Le nom est l'alternative textuelle ; à côté d'un nom déjà écrit (carte, liste), l'avatar est déclaré `decorative` et masqué aux lecteurs d'écran. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-parlementaireavatar--docs)

## Import

```tsx
import { ParlementaireAvatar } from "@clair/ui";
```
