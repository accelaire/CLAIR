import { ScrutinCard } from "@clair/ui";

Carte d'un scrutin : numéro, chambre, date, titre (unique lien, vers le scrutin), décompte des voix en texte (pour, contre, abstention) et sort en badge texte. Le badge « Important » vient d'un classement calculé par CLAIR et l'annonce comme tel. Remplace `ScrutinListCard` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-scrutincard--docs)

## Import

```tsx
import { ScrutinCard } from "@clair/ui";
```
