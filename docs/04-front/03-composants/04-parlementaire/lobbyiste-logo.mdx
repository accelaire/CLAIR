import { LobbyisteLogo } from "@clair/ui";

Logo d'un représentant d'intérêts inscrit au répertoire de la HATVP. Sans logo, ou s'il ne se charge pas, les initiales du nom le remplacent. L'adresse du logo est fournie par l'application : le composant n'appelle aucun service tiers. Remplace `LobbyisteLogo` du site actuel. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-lobbyistelogo--docs)

## Import

```tsx
import { LobbyisteLogo } from "@clair/ui";
```
