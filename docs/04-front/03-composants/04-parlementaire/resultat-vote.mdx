import { ResultatVote } from "@clair/ui";

Répartition des voix d'un scrutin : une barre empilée (pour, contre, abstention) et sa légende, qui donne chaque valeur et son pourcentage en texte. La barre est décorative, la légende porte l'information. Les pourcentages sont calculés sur les voix exprimées et les abstentions. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-resultatvote--docs)

## Import

```tsx
import { ResultatVote } from "@clair/ui";
```
