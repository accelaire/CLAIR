import { DataTable } from "@clair/ui";

Tableau de données générique, construit sur `Table` de Mantine. La légende est obligatoire (elle peut être masquée visuellement) et nomme aussi la zone de défilement horizontal, atteignable au clavier sur mobile. Une colonne devient triable avec `sortValue` : son en-tête porte un bouton, `aria-sort` et une annonce du tri. Le tri peut être local, contrôlé (lu dans l'URL) ou fait par le serveur (`manualSort`). Remplace `ClassementsTable` et `ComparisonVotesTable` du site actuel. Exemples : personnes fictives. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-parlementaire-datatable--docs)

## Import

```tsx
import { DataTable } from "@clair/ui";
```

## Avec un tri

<Preview>
  <DataTable
    caption="Classement d'exemple, triable"
    getRowKey={(ligne) => ligne.id}

    rows={[
      { id: "1", nom: "Camille Exemple", amendements: 148 },
