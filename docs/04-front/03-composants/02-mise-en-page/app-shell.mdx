import { AppShell, Footer, Header } from "@clair/ui";

Cadre de toutes les pages du site : lien d'évitement, bandeau éventuel, en-tête, contenu principal (`main#contenu`, cible du lien d'évitement) et pied de page. `apps/site` l'utilise dans son layout. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-mise-en-page-appshell--docs)

## Import

```tsx
import { AppShell } from "@clair/ui";
```

## Utilisation de base

<Preview surface="page">
  <AppShell

```tsx
<AppShell header={<Header navigation={navigation} />} footer={<Footer columns={colonnes} />}>
  <h1>Titre de la page</h1>

```
