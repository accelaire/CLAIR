import { Bandeau } from "@clair/ui";

Bandeau d'annonce placé au-dessus de l'en-tête (prop `banner` de `AppShell`). Le ton « direct » ajoute la mention « En direct » et une pastille animée, immobile si les animations sont réduites ; la couleur n'est jamais seule. L'application décide de l'afficher et lui passe ses données. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-mise-en-page-bandeau--docs)

## Import

```tsx
import { Bandeau } from "@clair/ui";
```

## Avec un bouton de fermeture

<Preview surface="page">
  <Bandeau dismissible dismissLabel="Masquer l'annonce">
    La documentation des données a été mise à jour.
  </Bandeau>
</Preview>

```tsx
<Bandeau
  dismissible
  dismissLabel="Masquer l'annonce"
  onDismiss={() => sessionStorage.setItem("clair:bandeau-ferme", "1")}
>
  La documentation des données a été mise à jour.
</Bandeau>
```
