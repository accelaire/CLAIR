import { Badge, PageHeader, ShareButton } from "@clair/ui";

En-tête de page, à placer une fois en tête du contenu principal : il porte le seul `h1` de la page. Le fil d'Ariane est une `nav` nommée « Fil d'Ariane » ; la page courante, dernier élément, n'est pas un lien et porte `aria-current="page"`. `Breadcrumb` s'utilise aussi seul. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-mise-en-page-pageheader--docs)

## Import

```tsx
import { Breadcrumb, PageHeader } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <PageHeader
    title="Scrutins"
    description="Tous les votes publics de l'Assemblée nationale et du Sénat."
  />

```tsx
<PageHeader

  description="Tous les votes publics de l'Assemblée nationale et du Sénat."
```
