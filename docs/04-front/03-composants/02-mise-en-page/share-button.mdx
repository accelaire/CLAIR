import { ShareButton } from "@clair/ui";

Bouton de partage d'une page : il ouvre le partage natif du navigateur (Web Share API) quand il existe, sinon il copie le lien dans le presse-papier ; la confirmation « Lien copié » est visible et annoncée aux lecteurs d'écran (`aria-live`). Si la copie échoue, le lien s'affiche pour être copié à la main. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-mise-en-page-sharebutton--docs)

## Import

```tsx
import { ShareButton } from "@clair/ui";
```
