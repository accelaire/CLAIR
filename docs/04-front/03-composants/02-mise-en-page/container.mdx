import { Container } from "@clair/ui";

Conteneur qui centre le contenu, limite sa largeur à celle du site (`--clair-largeur-contenu`) et pose les marges latérales ; la taille `etroit` donne une colonne de lecture pour les textes longs. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-mise-en-page-container--docs)

## Import

```tsx
import { Container } from "@clair/ui";
```

## Utilisation de base

<Preview>
  <Container>
    <p>Contenu centré, à la largeur du site.</p>
  </Container>
</Preview>

```tsx
<Container>
  <p>Contenu centré, à la largeur du site.</p>
</Container>
```

```tsx
<Container size="etroit">
```
