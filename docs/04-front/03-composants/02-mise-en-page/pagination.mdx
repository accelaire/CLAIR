import { Pagination } from "@clair/ui";

Pagination dans une `nav` nommée « Pagination ». Préférer les liens (`hrefFor`) : présents dans le HTML servi, ils permettent aux moteurs d'explorer toutes les pages d'une liste. La page courante porte `aria-current="page"` ; sur un écran étroit, seuls « Précédent », « Page n sur N » et « Suivant » restent affichés. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-mise-en-page-pagination--docs)

## Import

```tsx
import { Pagination } from "@clair/ui";
```
