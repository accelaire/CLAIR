import { Tabs } from "@clair/ui";

Onglets accessibles (motif « tabs » du W3C, via Mantine) : les flèches passent d'un onglet à l'autre et chaque panneau est relié à son onglet. Le compteur est annoncé entre parenthèses. En mode contrôlé (`value` et `onChange`), l'onglet actif vit dans l'URL, ce qui permet de partager un lien vers un onglet. [Toutes les variantes dans l'atelier Storybook](https://storybook.clair.vote/?path=/docs/composants-mise-en-page-tabs--docs)

## Import

```tsx
import { Tabs } from "@clair/ui";
```

## Avec l'onglet actif dans l'URL

L'écran lit l'onglet dans l'URL (`?onglet=vote`) et la met à jour à chaque changement ; l'aperçu ouvre directement l'onglet « Vote ».

<Preview>
  <Tabs
    label="Détail du scrutin"
    defaultValue="vote"
    items={[
      { value: "amendements", label: "Amendements", content: <p>Amendements.</p> },
      { value: "vote", label: "Vote", content: <p>Détail du vote.</p> },
    ]}
  />
</Preview>

```tsx
const { navigate } = useNavigation();

<Tabs
  label="Détail du scrutin"
  value={params.onglet ?? "vote"}
  onChange={(onglet) => navigate(buildHref(pathname, { ...params, onglet }))}
  items={[
    { value: "amendements", label: "Amendements", content: <p>Amendements.</p> },
    { value: "vote", label: "Vote", content: <p>Détail du vote.</p> },
  ]}
/>
```
